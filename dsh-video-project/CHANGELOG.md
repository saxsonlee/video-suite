# 更新记录 · dsh-video-project

本文件记录每个版本的变更。README 只放用法与说明，不再重复更新日志。

## 2026-11-25
- 新增环境自检：`server/env-check.js` + `scripts/check-env.mjs` + `check-env.bat`（Node/ffmpeg/目录可写性）。
- 面板「设置 → 环境检查」卡片：显示 ffmpeg 状态与来源，缺失时可一键下载（`POST /env/fetch-ffmpeg`），后台执行并轮询结果。
- 新增路由 `GET /api/video-project/env`；Codex 面板同步支持。
- 背景：仓库不再提交 `vendor/ffmpeg/ffmpeg.exe`（100.5MB，超 GitHub 上限），新克隆需按提示补装。

## 2026-11-23
- 出图模型支持 MiniMax-H3-Image（尺寸与 response_format 自动适配；草图/三视图/场地图可用）。

## 2026-11-12
- 视频 tab：镜头版本列表（版本/大小/时长/类型/验收状态），详情抽屉（内嵌播放、版本信息、验收、修改标记、设为采用）。
- 版本区分「分镜片段 / 全片」：归档可标注 kind，自动 ffmpeg 探测时长/宽高并提示疑似全片。
- 采用版本：每个镜头可指定采用版本；全片保存按采用版本校验（未验收标「待验收」，记录来源版本）。
- 验收：面板直接验收通过/不通过/撤销；同一版本只保留最新验收记录；状态更新不刷新整页。
- 项目删除按钮（列表卡片底部 + 详情页顶部）。
- 分镜拆分自查：固定机位长镜头、多段动作、人物位置变化提示；面板即时显示拆分建议。
- 各功能独立图像模型（草图分镜 / 人物三视图 / 区域场地）。
- 视频预览/播放：媒体接口支持 mp4 Range，面板内播放（全片/版本）。
