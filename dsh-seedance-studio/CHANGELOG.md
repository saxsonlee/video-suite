# 更新记录 · dsh-seedance-studio

本文件记录每个版本的变更。README 只放用法与说明，不再重复更新日志。

## 2026-11-25
- Codex 面板支持「环境检查」：`/api/video-project/env`（复用视频项目自检逻辑）。
- 仓库不再提交 `vendor/ffmpeg/ffmpeg.exe` 与 `node_modules`，改为按需补装。

## 2026-11-23（MiniMax H3 接入）
- 新增 MiniMax 中转站协议（`/videos`）：`MiniMax-H3` 文生/图生视频，4~15 秒、768P/2K；
- 协议与请求体风格按默认模型自动识别（填 `MiniMax-H3` 即可，无需手填协议）；
- 产物下载走 `/videos/{id}/content` 并带鉴权头（新增下载鉴权支持）；
- 图像模型识别支持 `MiniMax-H3-Image`（可作为 video-project 出图模型）；
- 新增 `test/minimax.test.mjs`（9 项）。

## 2026-11-12（i18n 动态语言包）
- 动态语言包：`locales/<lang>.json`（新增语言 = 放文件 + 清单加代码），语言切换自动多语言；内置中/英/俄三语，中文兜底。
- DSH/Codex 面板内联语言包，独立 Web 版读取 locales 目录；测试改为校验所有语言键集一致。

## 2026-11-12（面板迭代）
- 版本详情内嵌视频：改为独立播放窗口（iframe），按视频真实宽高适配（竖屏/横屏任意比例），修复裁切/拉伸问题。
- 播放区域支持自动比例（读取 ffmpeg 探测的视频宽高），限制最大高度。
- 历史记录详情新增（点击卡片打开）：完整提示词（可折叠）、参数、状态、播放；成功记录内嵌视频。
- 主面板打开「视频创作」时显示最近历史（跨会话合并）；右侧会话窗口仍按会话过滤。
- 模型映射：中转站模式下自动把方舟粒度模型 ID 映射到中转站别名（修复 503 model_not_found）。
- 下载：失败自动重试 3 次、超时放宽到 10 分钟，成功的任务再次 wait/status 自动补下载。
- Codex 面板闪烁：历史轮询仅在生成中执行 + 幂等渲染（内容未变不重绘）。
- 新窗口打开链接、面板地址带版本号强制刷新。
- 全片保存校验：要求镜头已归档；未验收镜头标「待验收」；按采用版本验收。
- 测试 147 项通过。
